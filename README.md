
# Machine Learning Projects

A collection of Machine Learning experiments implemented using Python and Jupyter Notebook.

## Projects

### Data Preprocessing and Visualization
- Employee Data Preprocessing
- Titanic Data Exploration and Visualization

### Regression
- House Price Prediction using Linear Regression
- Regression Models Performance Comparison

### Classification
- Diabetes Prediction using Logistic Regression
- Iris Flower Classification using SVM
- Iris Classification using Decision Tree and KNN
- Classification Models Performance Comparison
- Perceptron and Adaline Classification

### Unsupervised Learning
- Customer Segmentation using K-Means
- PCA Dimensionality Reduction

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Repository Structure
- Jupyter notebooks contain the experiment code.
- `datasets/` contains datasets that are included in this repository.
- Each experiment README explains its dataset and implementation.
- `requirements.txt` lists the Python dependencies.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/gavhaneishwari04-hub/Machine-Learning-Projects.git
cd Machine-Learning-Projects
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the required notebook and follow its instructions.
